## Diseño
- Antes de crear o modificar cualquier pantalla, componente o estilo, lee y cumple DESIGN.md.
- Si cambias DESIGN.md, copia el cambio a .claude/skills/nortvira-design/references/DESIGN.md.

**Jerarquía de prioridad entre skills de diseño**, para cuando haya contradicciones:
1. DESIGN.md y la skill `nortvira-design` (decisiones propias de Nortvira).
2. Skills oficiales de Anthropic (`frontend-design`).
3. Skills de terceros (`impeccable`, `emil-design-eng`, `design-taste-frontend`, `redesign-existing-projects`): solo asesoras.

Si una skill de nivel inferior contradice a una superior, gana la superior y se comenta en una línea.
